# Aventura do Polo - UniGames 🎮

## Português
Jogo feito na Unity para o UniGames.

### Como jogar
1. Vá até a aba [Releases](https://github.com/DiogoTadashi/Aventura-do-Polo-Unigames/releases).
2. Baixe o arquivo `.zip` da versão mais recente.
3. Extraia o conteúdo.
4. Execute o arquivo `PoloAdventure.exe`.

## English
Game made in Unity for UniGames.

### How to play
1. Go to the [Releases](https://github.com/DiogoTadashi/Aventura-do-Polo-Unigames/releases) tab.
2. Download the `.zip` file from the latest version.
3. Extract the contents.
4. Run the `PoloAdventure.exe` file.
